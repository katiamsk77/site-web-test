# katia-magnetiseur.com

Site vitrine de Katia Messica — magnétiseuse, énergéticienne et coupeuse de feu au Teich (Bassin d'Arcachon).

Site statique en HTML/CSS/JS, sans dépendance : il suffit de déposer les fichiers sur n'importe quel hébergement (GitHub Pages, Netlify, OVH…).

## Pages
- `index.html` — Accueil
- `qui-suis-je-katia-messica-magnetiseuse/` — Qui suis-je ?
- `magnetisme-coupe-feu-coupeuse-de-feu-le-teich-bassin-arcachon-aquitaine/` — Magnétisme & Coupe-feu
- `soins-energetiques-le-teich-bassin-arcachon/` — Soins énergétiques
- `mes-tarifs-magnetiseur-bassin-arcachon-le-teich-energeticienne/` — Tarifs
- `contact-prise-de-rendez-vous-entretien-decouverte-gratuit-bassin-arcachon-le-teich/` — Contact
- `mentions-legales/` — Mentions légales & confidentialité

Les adresses des pages reprennent celles de l'ancien site pour conserver le référencement.
